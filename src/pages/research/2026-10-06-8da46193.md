# Obsidian Git 플러그인을 iCloud 같은 별도 동기화와 같이 써도 되는가 — 공식 입장과 알려진 문제

> **한 줄 결론**
> **조건부** — git 을 데스크톱 한 대에서만 돌리고, git 기록 폴더를 노트 폴더 밖·iCloud 밖에 두고, 휴대폰에서는 git 을 돌리지 않으면 쓸 수 있다. 공식 안내서가 바로 그 형태를 전제로 회피책을 적어 두었고 [1], 반대로 기록 폴더까지 클라우드로 복제되면 손상 위험이 생긴다 [2]. — 확신도 **중간** (재확인 통과 2/3 · 비판자: 전체를 검증 완료된 조사로 신뢰하기는 어렵다.)

## 1. 요약

- 공식 안내서는 휴대폰에서 iCloud 저장을 고르지 말라면서도, 데스크톱 절은 iCloud 병용을 전제로 git 기록 폴더를 노트 폴더 밖으로 빼는 법을 알려 준다 [1].
- Obsidian 팀 문서는 유료 동기화와 클라우드 저장소의 병용만 말리고, git 은 금지가 아니라 동기화 선택지로 적어 둔다 [3][4].
- 위험한 쪽은 노트 본문이 아니라 git 이 이력을 적는 내부 기록이고, git 쪽 공식 문답이 이를 클라우드로 주고받으면 깨질 수 있다고 경고한다 [2].

## 4. 엇갈리는 점

- 손상 사례의 원인 귀속이 엇갈린다 — 작업 막힘·받아오기 멈춤을 iCloud 탓으로 정리한 쪽이 있으나, 원문에는 그 말이 없었다 [10][11].
- '다른 동기화 서비스' 병합 설정이 파일을 안 건드린다는 설명은 구현과 다르다 — 데스크톱 쪽은 올려둔 목록까지 바꾸고, 휴대폰 쪽엔 그 분기가 없다 [12][13][7].
- 잘 쓴다는 증언(1년·6~7개월)은 스스로 고른 표본이라 깨진 수를 모른다. 같은 글도 조각을 못 찾는 오류를 적었다 [14][15].

## 5. 아직 모르는 것

- '한 폴더를 여러 서비스로 동기화하지 말라'는 일반 경고가 Obsidian 팀 문서 어디에 있는지 확정되지 않았다 [16][3].
- iCloud 가 git 내부 기록에 중복 파일을 만드는 조건과 빈도는 재현 자료가 없다 — 가능한 시나리오까지만 확인됐다 [2].
- 내용이 비워진 파일이 휴대폰 쪽 플러그인에 어떻게 보이는지 실제 기기로 확인되지 않았다 [9][7].
